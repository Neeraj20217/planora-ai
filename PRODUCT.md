# Product

<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
User-approved Next.js App Router, TypeScript, Tailwind CSS, Lucide, and Zod. Vitest and React Testing Library for Phase 1.

## Users
Individual organizers of weddings, birthdays, and community events, using desktop, tablet, or mobile.

## Product Purpose
Turn event requirements into actionable, editable planning artifacts with budgets, timelines, vendor categories, and personalized ideas. Phase 1 establishes the accessible brief and navigation only.

## Capabilities and Constraints
INR by default; date-only events interpreted in Asia/Kolkata. Financial values use integer paise. No Gemini, persistence implementation, deployment, or Phase 2 work in this delivery. Only the main Git branch is allowed; tracked repository must stay below 10 MB.

## Evidence on Hand
docs/DEVELOPMENT_PLAN.md and the user's explicit Phase 1 approval. No customer testimonials, verified vendor data, or live AI functionality exists yet.

## Accessibility & Inclusion
Semantic HTML, visible keyboard focus, associated labels and errors, readable contrast, responsive layout, and reduced-motion support.

## Open Decisions
No user-pinned visual identity. Visual choices for this implementation are engineering design decisions, not claims of an approved brand system. Hackathon platform eligibility remains unresolved as documented in the plan.
