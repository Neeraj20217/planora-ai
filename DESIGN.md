# Planora visual foundation

Operate mode: a calm, readable celebration brief, with an editorial planner's hierarchy. The form is the main task; a narrow guidance margin supports it. No imagery is needed for this data-entry surface.

Design decisions for this implementation (not a user-pinned brand): warm ivory paper, forest-green actions, subdued sage guidance panels; DM Sans for controls and Libre Baskerville for main headings. Typography is bundled locally, so build and runtime do not depend on font services. Thin rules separate sections; selection uses a visible check plus fill and border. Error states use words, field associations, and focus, as well as red.

The source concepts considered were an invitation suite, a volunteer running sheet, an editorial planner, a family calendar, a venue worksheet, a recipe notebook, and a community noticeboard. The direction seed assigned candidate 3: editorial planner. Other visual sources were declined where their motion, media focus, or symbolic notation would obscure accessible form entry. Retained disciplines: stable alignment, progressive information grouping, and explicit state signaling.

Desktop: full-width navigation, main form plus supporting margin. Mobile: navigation wraps into its own row, form controls become one column, guidance follows the task. Essential copy and control labels remain visible. Normal text uses high-contrast ink; focus uses a 3px ochre outline. Reduced-motion preferences disable transitions. No decorative animations, mock data, fabricated metrics, or pretend AI controls.

Future pages should preserve this typographic and interaction system unless the user requests a new direction.

Phase 2 extends this system with section anchor navigation, ruled budget rows with tabular figures, labeled native checkboxes/progress, native vendor status selects, explicit generation/sharing states and local save/error notices. It preserves the existing type, palette and responsive behavior; it adds no new visual identity. Fixture screenshots must be labeled as test data, never presented as live model output.
